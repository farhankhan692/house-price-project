5Stage 5: Least-Squares Solvers (Normal Equations & QR)
Input: Design Matrices A_k, Target y ▾

Input: Design matrices A_k and target vector y.

Formulation: Solve for optimal weight vector β:

1. Normal Equations: (Aᵀ A) β = Aᵀ y ==> β = (Aᵀ A)⁻¹ Aᵀ y 2. Gram-Schmidt QR: A = Q R ==> R β = Qᵀ y 3. Projection Matrix: P = A (Aᵀ A)⁻¹ Aᵀ
